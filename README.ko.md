# SignalDesk

서버·API의 상태에서 로그, 트레이스, 알림, 장애 대응까지 연결하는 운영 모니터링 플랫폼입니다. 한국어 UI와 직접 실행 가능한 API·수집기·작업 엔진을 포함합니다.

![대시보드](docs/screenshots/overview.png)

## 실행

Node.js 24 이상이 필요합니다.

```bash
npm ci
npm run build
npm start
```

**http://127.0.0.1:4319**에서 확인하세요. Demo는 고정 예제 데이터, Live는 실제 수집 데이터입니다. Live에서는 로컬 CPU·메모리와 플랫폼 API 트레이스를 수집합니다. 기존 서버에 자동 연결되지는 않습니다.

```bash
node examples/send-sample.mjs
node examples/ai-span.mjs
```

예제 코드는 Live에 `example-*` 이름으로 이벤트를 전송합니다. AI 예제는 실제 모델을 호출하지 않습니다.

## 포함한 기능

| 화면        | 동작                                                              |
| ----------- | ----------------------------------------------------------------- |
| 대시보드    | 공통 환경·서비스·시간 필터, 요청량·오류율·지연, 장애와 운영 상태  |
| 서비스·API  | RED 지표, 신선도, 관련 로그·트레이스, 수집 스팬 기반 서비스 연결  |
| 인프라      | 호스트 CPU·메모리, 실제 로컬 수집, 외부 호스트 수집 API           |
| 로그        | 메시지·수준 필터, 가상 목록, 페이지 탐색, JSON 내보내기           |
| 트레이스    | 부모·자식 워터폴, 지연·실패 스팬, 속성                            |
| 알림        | 서비스별 규칙, 임계치 미리보기, 지속 시간, 데이터 없음, 확인·중지 |
| 알림 전달   | 암호화 Webhook 주소, 전달 이력, 최대 5회 재시도                   |
| 장애        | 담당자, 상태, 알림 연결, 조사 메모와 타임라인                     |
| 분석        | 루트 스팬 표본 성공률, 오류 그룹, 시간·서비스 히트맵              |
| AI 워크로드 | 모델·토큰·지연·제공된 비용·평가 근거, 트레이스 연결               |
| 연결·설정   | API 가용성 검사, 수집 상태, 변경 이력, 역할 토큰                  |

시각화는 ECharts 6.1, 로그는 TanStack Virtual을 사용합니다. 그래프는 확대·시리즈 선택·숫자 표를 제공하고, 화면 간 이동은 서비스와 시간 맥락을 유지합니다.

## 확장 구조

공유 계약, UI, 수집·조회 경계, 제어 데이터, 알림 엔진을 분리했습니다. 비동기 `TelemetryStore` 구현을 주입할 수 있고 실제 계약 테스트가 있습니다. 현재 제공하는 저장 엔진은 SQLite WAL 하나입니다. Prometheus·Loki·Tempo·ClickHouse 연결은 다음 단계입니다.

지금 버전은 단일 인스턴스 기반입니다. 대규모 분산 운영을 위해서는 원격 저장소 외에 공유 제어 DB, 작업 리스, 큐, 집계가 추가되어야 합니다. 자세한 경계는 [설계 문서](docs/ARCHITECTURE.md)를 확인하세요.

## AI 적용 판단

Langfuse·Opik·Phoenix·OpenTelemetry GenAI를 조사했습니다. AI 서비스의 토큰·비용·품질 평가와, AI가 운영 장애를 분석하는 기능은 분리합니다.

현재는 AI 호출 관측과 **로컬 규칙 기반 근거 브리핑**을 구현했습니다. 실제 LLM 기반 원인 분석이나 자동 복구는 구현하지 않았습니다. 비용은 출처가 제공된 값만 합산하고, 프롬프트·응답·도구 인자 본문은 수집 시 제거합니다.

## Docker

```bash
npm run --silent credentials > .env
docker compose up --build -d
```

http://127.0.0.1:4320에서 `.env`의 admin 토큰으로 연결합니다. `.env`는 커밋하지 마세요. 이 파일의 키는 채널 복호화와 접근 제어에 쓰이므로 안전하게 보관해야 합니다.

## 검증과 현재 경계

```bash
npm run check
```

수집 원자성·중복 처리, 접근 제어, 알림 지속 시간·복구·데이터 없음, 재시도, 저장 후 재시작, 비동기 어댑터, OTLP JSON, SDK 큐를 검증합니다. 브라우저·컨테이너·CI 실행 결과는 [검증 기록](docs/VERIFICATION.md)에 남깁니다.

기본 보존은 7일, 이벤트 상한은 100만 개입니다. 대시보드와 AI 분석은 조회 상한 내 관측 표본입니다. 전체 트래픽의 SLO나 비용 정산으로 해석하면 안 됩니다. OTLP는 HTTP JSON 트레이스 일부만 지원하고 protobuf/gRPC는 지원하지 않습니다.
